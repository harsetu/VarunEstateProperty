# res — bundled assets

Put images here and register them in `index.ts`, then use `images.<group>.<name>` (Vite hashes and
serves them). Listing photos are *data* (they come from the API / flavor sample data) and are not stored here.

```
res/images/categories/   property-type artwork
res/images/hero/         hero / quote / page banners
res/images/placeholder-property.svg   fallback for listings without a photo
```
